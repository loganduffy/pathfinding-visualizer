# How to Run

1. Clone the repository with HTTPS

```
git clone https://github.com/loganduffy/pathfinding-visualizer.git
```
2. Make sure you're in the root directory (```/pathfinding-visualizer```)

4.  Run the program with
```
npm run dev
```
